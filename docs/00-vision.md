# Visión

## Qué queremos lograr

Un sistema repetible para lanzar infoproductos low ticket (US$ 5 a US$ 30 de entrada) con tráfico pago, en distintos nichos, que:

1. **Arranque rápido:** un producto nuevo pasa de idea a primer anuncio en días, no semanas, porque el método y las plantillas ya existen.
2. **Falle barato:** cada paso tiene un criterio de salida y cada test cuesta poco y se registra.
3. **Escale con datos:** se escala lo que mide bien, se corta lo que no, con reglas escritas.
4. **Aprenda solo:** cada producto deja aprendizajes que mejoran el método de los siguientes.
5. **Sea transferible:** cualquier agente, en cualquier PC, retoma un producto leyendo el repo.

## Qué NO es

- No es un repo de trucos. Todo lo que está acá resiste una auditoría de Meta y de Hotmart.
- No es un archivo de ideas sueltas. Cada idea pasa a decisión (`10-decisiones.md`) o se descarta con motivo.

## Modelo de negocio base

```
Anuncio (Meta) → Página de conversión → Checkout (Hotmart) + extras opcionales
   → Entrega (app/PDF) → Emails de acompañamiento → Venta siguiente (continuidad) → Prueba social real
```

Economía: entrada barata para bajar la barrera, extras de checkout para subir el ticket medio sin pedir más al principio, continuidad para capturar el valor de largo plazo. Las cuentas están en `playbook/formulas.md`.
